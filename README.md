# ai-research
A Repo for experiments and AI research


## Purpose

Controlled Experiments on how to get optimal behaviour from my AI agents - after reviewing current research on the topic.

## Running an experiment

- **New experiment issue:** use the Experiment issue form (`.github/ISSUE_TEMPLATE/experiment.yml`). Required fields are pre-registration: hypotheses, measures and success criteria are fixed before anything runs.
- **From a problem statement:** invoke the `experiment-issue` skill (`.claude/skills/experiment-issue/SKILL.md`). It fills the form's sections as an issue and ends by posting template and skill feedback on that issue.
